Project Description
This repository contains sample test scripts for the AttendX student attendance application.

Files
login_test.py: Demonstrates basic login input validation scenarios.
attendance_test.py: Demonstrates attendance data validation scenarios.

Requirements
Python 3
Git

How to Run
Run the following commands from the project directory:

python login_test.py
python attendance_test.py

Purpose
The repository demonstrates Git version control, commits, GitHub synchronization and change tracking for software testing scripts.
